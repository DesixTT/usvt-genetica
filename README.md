# AgriGen - USVT DNA Analyzer (MVP)

Aplicație web pentru analiza datelor genetice vegetale și generarea de rapoarte de rezistență la boli și secetă. 
Proiect dezvoltat pentru Universitatea de Științele Vieții din Timișoara (USVT).

## Funcționalități MVP
- Încărcare fișiere VCF (Variant Call Format)
- Detecție markeri genetici pentru toleranță la secetă (Demo: Porumb/Grâu)
- Generare raport simplificat pentru cercetători/fermieri

## Tehnologii folosite
- **Frontend:** Streamlit (Python)
- **Logică:** Python (prelucrare date genomice)
